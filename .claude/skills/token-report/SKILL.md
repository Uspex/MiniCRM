# Отчёт по токенам Claude Code

Запусти движок — он сам определит проект по текущему рабочему каталогу,
посчитает токены из транскриптов, сольёт результат в долговременное хранилище
и напечатает таблицу по дням (свежие сверху):

```
py "C:/Users/Oleksii/.claude/scripts/token_report.py"
```

Опции (необязательно):
- `--days N` — показать только последние N дней;
- `--project "<path>"` — другой проект;
- `--no-store` — не писать в хранилище (только показать).

После запуска кратко перескажи пользователю на русском: итог за сегодня и
суммарно по проекту. Всю таблицу не дублируй — она уже в выводе. Если данных
нет — так и скажи.

## Важно

- Цена — **оценка по тарифам API** (cache-write 1.25–2× от input, cache-read
  0.1×). При плане-подписке реальные списания могут отличаться.
- Данные хранятся в `~/.claude/token-usage/<slug>.json` и **не теряются** при
  стирании транскриптов или каталога проекта — при каждом запуске история
  мёржится по максимуму, а не перезаписывается.
- Движок и хранилище общие для всех проектов; этот скилл — лишь точка вызова.
